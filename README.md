# 上傳前假名化工具（NCCU ORD Pseudonymiser）

*[English](README.en.md)*

把 Excel 名冊裡的姓名換成固定代碼，再交給外部 AI 分析。
**對照表只留在自己的電腦，不上傳、不連網。**

**核心特徵：代碼跨檔、跨年一致。**
代碼由「本機鹽值 ＋ 姓名」以 SHA-256 算出，所以同一個人在所有檔案、
所有年度都是同一個代碼——**串接分析與跨年追蹤完全不受影響**。
這一點是多數同類工具沒有做的（多半是每份文件各自產生隨機碼），
也是這個工具存在的理由，詳見〈[與其他工具的關係](#與其他工具的關係)〉。

適合行政與校務分析人員：不必會寫程式、不必開命令提示字元，點兩下就能用。

## 這個工具解決什麼問題

行政業務經手的資料有兩類：

| | 例子 | 直接上傳 AI 平台 |
|---|---|---|
| **公開資料** | 計畫執行情形查詢、系所師資、公開統計 | 風險低 |
| **因職務才接觸得到的資料** | 教師名冊、員工編號、申請與審查紀錄 | **有個資外洩風險** |

麻煩的是，分析通常要把兩類**串接**起來才有意義，而串接的鍵值往往就是姓名。
一旦要串接，第二類就得跟著上傳——此時第一類再公開也沒有用，
**整批資料的風險由最敏感的那一份決定。**

這個工具就是上傳前的那一道閘：所有要上傳的檔案都先過一次，
姓名換成 `T-XXXXXXXXXX` 形式的代碼，對照表留在本機。
同一個人在所有檔案、所有年度都是同一個代碼，**跨檔比對與跨年追蹤完全不受影響**。

## 安裝與使用

### 給不熟電腦的同仁（建議路徑）

1. 按 [Releases](../../releases) 下載最新的 zip，解壓縮
2. 把整個資料夾**移到本機硬碟**，例如 `D:\假名化作業\`
   （不要放在 OneDrive、Dropbox、Google 雲端硬碟等會自動同步的位置——
   工具會自己檢查，位置不對會跳警告）
3. 點兩下 `1_第一次執行_安裝環境.bat`，全自動，最後會建立桌面捷徑
4. 點兩下桌面捷徑，開始使用

### 給開發者

```bash
git clone https://github.com/<your-account>/<repo>.git
cd <repo>
pip install -r requirements.txt

python anonymize_gui.py      # 視窗介面
python anonymize.py          # 命令列，處理目前專案的 input
python anonymize.py --dry-run          # 只檢視，不寫出任何檔案
python anonymize.py --decode T-XXXXXXXXXX   # 代碼還原查詢
```

`requirements.txt` 裡的 `tkinterdnd2` 是選用的，只影響能不能把檔案直接拖進視窗。

## 操作流程

```
步驟零  選擇或新增專案          一件業務一個資料夾，代碼各自獨立
步驟一  把檔案放進 input        拖曳、選檔或直接丟進資料夾
步驟二  ① 先檢視  ② 進行假名化   先確認抓到的欄位正確，再實際執行
步驟三  ③ 檢視                  同時開啟 output 與 _private 核對
```

資料夾長這樣：

```
假名化工具/
└── 專案/
    ├── 示範專案/
    │   ├── input/      原始檔（不可上傳）
    │   ├── output/     假名化後（可以上傳）
    │   └── _private/   salt.txt、mapping.csv（絕對不可外流）
    └── 你的業務名稱/
        └── ...
```

---

## 三條必須知道的規則

**一、只有 `output` 裡的檔案可以上傳。**
`input` 是原始檔，`_private` 是對照表，兩者都不可以外流。

**二、`_private\salt.txt` 從頭到尾必須是同一個。**
代碼是「鹽值 ＋ 姓名」算出來的。鹽值不變，就可以隨時重跑、分批處理、
中途補檔，代碼永遠一致。刪掉 `_private` 再跑會產生新鹽值，所有代碼重新洗牌，
今年與去年就對不起來。

**三、專案 ＝ 一件「業務」，不是一個「年度」。**
需要跨年追蹤的業務，年年都用同一個專案。每年開新專案等於每年換一次鹽值。

## 主要功能

- **多專案**：一人多案時各自隔離，不同專案的代碼互不相干
- **姓名整併**：同一個人被打成兩種寫法（多空格、錯字）時，可以指定併為同一代碼
- **疑似個資欄位警告**：認不出的欄名會提醒，而不是靜靜跳過
- **雲端位置偵測**：工具資料夾若在同步資料夾內，開啟即警示
- **失敗一定說得出話**：沒處理好就不會顯示「完成」
- **代碼還原**：`--decode` 或視窗下方的查詢框
- **解除安裝**：`9_解除安裝.bat`，備份、逐檔 SHA-256 驗證、四道關卡後才刪

## 這個工具做不到的事

寫在前面比較誠實。完整清單見「使用說明.txt」的〈工具做不到的事〉一節：

- 同一張工作表上下兩段表格，只會認出第一段的表頭
- 三字姓名夾在句子裡也會被換掉（「長江大海的研究」會變成「長T-… 的研究」）
- 兩個字的姓名在句子中不自動替換，只在前後文明確時提醒
- 直式表單、複雜合併儲存格只提醒、不自動處理

這些都是**刻意的取捨**：寧可換成代碼（可用 `mapping.csv` 還原），
也不要清空（不可逆）；寧可多提醒，也不要靜靜漏掉。

**欄名可以自己增補。** 把 `欄位設定_範例.txt` 複製成 `欄位設定.txt` 放在同一層，
就能加入預設清單沒有的欄名，不必改程式。英文名冊請參考
[`field_settings_example_EN.txt`](field_settings_example_EN.txt)
（區塊標記 `[姓名欄]`、`[清空欄]` 必須維持中文，欄名本身可用任何語言）。

| 指標 | v2.4 | v2.6 |

| 殘留多於 v2.4 的表格 | — | **0 張** |
| 回歸測試 | — | 669 / 673 通過 |

未通過的 4 項是刻意保留的已知限制，用來標記「這是限制、不是迴歸」。

完整紀錄（17 條問題、126 條改動、逐條附行號與實跑輸出）見

## 示範資料

`專案/示範專案/` 附了 4 份**虛構**的示範檔，姓名使用武俠小說角色。
跑一次應該得到：

```
處理檔案　　：4
替換儲存格　：69
本次新增姓名：17（累計 17）
```

中途會出現一段「偵測到疑似同一人的不同寫法」的橘色提醒，那是刻意設計的，
用來示範姓名整併功能。

**本專案不含任何真實個人資料。**
v2.8 起，示範檔中原本一個疑似真實人名的範例已改為虛構人物（Wei Xiaobao），
用來示範「同一人有無空格兩種寫法」的情境。

## 與其他工具的關係

這個領域已經有不少成熟的工具，先講清楚差別，你才知道該不該用這一個。

| 工具 | 形態 | 代碼是否跨檔一致 | 適合誰 |
|---|---|---|---|
| **本工具** | Windows 桌面程式，一鍵安裝 | **是**（鹽值長期保存，跨年也一致） | 行政／校務分析承辦人 |
| [data-deidentification](https://github.com/dean9703111/data-deidentification) | 純前端網頁 | 否（隨機碼，且以單一文件為範圍） | 需要 PDF／Word／多格式的人 |
| [Microsoft Presidio](https://github.com/microsoft/presidio) | Python 函式庫 | 可自行實作 | 開發者，要接進自己的管線 |
| [ARX](https://arx.deidentifier.org/) | Java 桌面程式 | 不適用（做的是不可逆匿名化） | 研究者，要做 k-anonymity 等統計揭露控制 |
| IRI CellShield 等商業產品 | Excel 增益集 | 視設定 | 有預算、要原廠支援的單位 |

**什麼時候該用別的工具，而不是這一個：**

- 你要處理的是 **PDF、Word 或純文字**，不是 Excel 名冊
  → 用 [data-deidentification](https://github.com/dean9703111/data-deidentification)，格式覆蓋遠比這裡完整，還有人工覆核的預覽介面
- 你要把去識別化**接進程式或資料管線**
  → 用 [Presidio](https://github.com/microsoft/presidio)，這裡的設計是給人點的，不是給程式呼叫的
- 你要的是**不可逆的匿名化**、要做 k-anonymity 風險評估
  → 用 [ARX](https://arx.deidentifier.org/)。這個工具做的是**假名化**，只要鹽值還在就能還原，性質完全不同
- 你的資料是**中文以外的名冊**
  → 姓名判斷與預設欄名清單是針對繁體中文環境設計的，直接用會漏很多。
    欄名可以用「欄位設定.txt」自行擴充，但中文姓名的判斷邏輯不適用

**那什麼時候該用這一個：**

你每年都要做同一件業務的分析，需要把好幾份 Excel 名冊接起來比對，
而且明年還要跟今年比；操作的人不會寫程式，也不該被要求開命令提示字元。
